# MarlboroRed - TV Girl Music Player

A minimalist, aesthetic music player built using **Python** and **Pygame**, themed around the iconic pink-dark color palette of TV Girl.

## Features
- Automatic loading for audio, lyrics (.lrc), and album cover art.
- Interactive custom timeline slider and volume control.
- Synchronized rolling lyrics stream with past/future fade-out.
- Dynamic neon-pink audio spectrum visualizer wave.
